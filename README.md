## 快速开始

**只想看题**：双击 `题库/图论全章节题库/index.html`，左侧章节树 → 小节 → 题目（含图）。

**想离线答题**：装好 [OCS 油猴脚本](https://github.com/ocsjs/ocsjs) → 「⚙️ 全局设置 → 本地题库 → 导入题库文件」→ 选 `题库/图论全章节题库/questions.json`。

**想自己刷别的课**：见 [tools/bank-builder/USAGE.md](tools/bank-builder/USAGE.md)。

## 字段说明

```jsonc
{
  "id": "183c9e677f",
  "chapter": "2",
  "chapterName": "2.2 图的连通性",
  "type": "单选题",              // 单选题 | 多选题 | 判断题 | 连线题
  "title": "完全二部图的边数为（ ）。",
  "options": ["m+n", "mn", "m+n-1", "mn-1"],
  "answer": "B",                 // 多选 "A,C"；判断 "对"/"错"；连线 "1-B 2-B 3-B 4-B"
  "images": ["images/xxx.png"],  // 本地相对路径
  "verified": true,              // 平台判分确认过
  "flags": [],                   // 疑点：未验证 / 答案冲突 / 不支持题型 / 答案不完整 / 半对半错
  "explanation": "完全二部图 K_{m,n} 的边由两部分间所有配对构成，共 m×n 条。"
}
```

连线题额外有 `subItems` / `groups`，查看器按「每张图一道选择题」展示：

```jsonc
{
  "type": "连线题",
  "groups": ["欧拉图", "非欧拉图"],
  "answer": "1-B 2-B 3-B 4-B",
  "subItems": [{ "no": 1, "answer": "B", "target": "非欧拉图" }]
}
```

## 说明

- 题库由采集工具在**本人的课程账号**上自动作答、按平台判分结果回炉得到，`verified: true` 表示平台确认答对。
- 图片已本地化（平台图片需要登录、URL 会失效），拷贝整个目录即可离线查看。
- 仅用于个人学习复习，请勿用于违反课程规定的用途。
